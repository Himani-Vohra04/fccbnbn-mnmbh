# Boyfriend's Day — Bubu & Dudu-inspired love website

A responsive, single-page romantic website using the photos and short videos supplied in the chat.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Host free with GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything inside this folder** (keep the `assets` folder).
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/root`, then Save.
6. GitHub will give you the live `github.io` address.

## Personalize
Edit `index.html` to change the letter, captions, or title. The design is intentionally self-contained; no framework or build step is required.

The visual theme is inspired by cute bear/panda love stationery rather than using third-party character artwork.
